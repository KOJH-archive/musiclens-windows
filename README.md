# MusicLens v1.1 — Windows 트레이 음악 인식

MusicLens는 Windows 기본 출력 장치에서 재생되는 소리를 듣고 곡명과 아티스트를 알려 주는 개인용 실험 앱입니다. YouTube와 브라우저를 포함한 **시스템 출력 전체**를 WASAPI Loopback으로 읽으며, 마이크는 사용하지 않습니다. 앱은 평소 트레이에 머물고 곡을 찾았을 때만 화면 오른쪽 아래에 알림을 표시합니다.

> ShazamIO는 비공식 Shazam 접근 라이브러리입니다. 서버 가용성, 정확한 호출 한도, 장기 호환성은 보장되지 않습니다. 공식 상용 서비스로 제공하기 전에는 API와 이용 조건을 별도로 검토해야 합니다.

## 빠른 시작

1. Windows 11에서 Python 3.12 또는 3.11과 `py` 런처가 설치되어 있는지 확인합니다.
2. 처음 실행하거나 라이브러리 설치가 필요하면 `start_debug.bat`를 더블클릭합니다. 필요한 패키지를 설치한 뒤 앱을 실행하며, CMD 창을 열어 오류를 볼 수 있습니다. 설치에는 인터넷이 필요합니다.
3. 이후 일상 실행은 `start.bat`를 더블클릭합니다. CMD 창은 잠깐 보였다가 닫히며, 앱은 시계 옆 **숨겨진 아이콘(∧)** 영역의 음표 아이콘으로 남습니다.
4. 곡을 바로 확인하려면 트레이 아이콘을 우클릭하고 **지금 검색**을 누릅니다. 앱이 자동 인식을 계속하려면 **자동 인식 켜기**가 선택되어 있어야 합니다. 기본값은 켜짐입니다.

이미 MusicLens가 실행 중일 때 `start.bat`를 다시 누르면 새 앱을 만들지 않고 기존 앱의 상태/설정 창을 엽니다. 업데이트 직후 기존 프로세스가 이전 코드를 쓰는 경우에는 트레이 메뉴의 **종료**로 한 번 닫고 다시 실행해야 합니다.

## 사용 방법

- **트레이 아이콘 더블클릭:** 상태/설정 창 열기. 창의 `×`는 창만 숨깁니다.
- **상태/설정 창의 아래 두 줄:** 현재 단계와 마지막 검색 결과를 따로 표시합니다. 같은 곡이라 팝업을 생략했는지, Shazam에서 일치하는 곡이 없었는지 확인할 수 있습니다.
- **트레이 우클릭 → 자동 인식 켜기:** 백그라운드 감시를 켜거나 끕니다.
- **트레이 우클릭 → 지금 검색:** 수동으로 12초를 수집해 검색합니다. 자동 인식이 꺼져 있어도 사용할 수 있습니다.
- **트레이 우클릭 → 설정 (인식 주기):** 15, 30, 60, 120초 중 선택합니다. 상태/설정 창에서도 선택할 수 있습니다.
- **상태/설정 창의 음성 처리 선택:** 기본 `분리 안 함` 또는 `빠른 음성 억제`를 선택할 수 있습니다. 후자는 음성과 음악이 섞인 영상에서 음성 대역을 가볍게 줄인 뒤 검색합니다. 완전한 AI 음원 분리는 아니므로 음악 자체도 일부 약해질 수 있습니다.
- **트레이 우클릭 → 종료:** 트레이 아이콘을 제거하고 캡처 및 작업 스레드가 끝날 때까지 기다린 뒤 종료합니다.

인식에 성공하면 곡명과 아티스트가 화면 오른쪽 아래에 약 9초 표시됩니다. 유효한 Shazam 링크가 있으면 팝업에서 열 수 있습니다. 같은 날 같은 곡이 반복 인식될 때는 팝업을 반복하지 않지만, 날짜가 바뀌면 이전에 검색된 곡도 다시 알립니다.

## 자동 인식의 정확한 동작

1. 자동 인식이 켜지면 기본 출력 장치의 소리를 약 0.25초 단위로 확인합니다. RMS가 기준값을 넘는 구간이 두 번 연속 나오면 소리 활동으로 봅니다. 이는 **음악 분류기가 아니므로** 대사나 효과음도 조건에 맞으면 검색을 시작할 수 있습니다.
2. 소리가 감지되고 다음 검색 시각이 되면 약 12초의 출력음을 메모리에 모읍니다. 12초 구간이 무음에 가까우면 Shazam 요청을 건너뜁니다.
3. ShazamIO가 오디오에서 지문을 만들고 Shazam에 검색합니다. 앱의 검색 대기 제한은 22초입니다. 결과가 있으면 제목과 아티스트를 표시합니다.
4. 검색이 끝난 시점부터 선택한 주기만큼 기다립니다. 소리가 계속 나면 다음 검색을 진행해 곡 변경을 확인합니다. 무음이면 다음 소리가 날 때까지 Shazam을 호출하지 않습니다.

따라서 기본 15초는 **검색 완료 후 다음 12초 수집을 시작하기까지의 최소 대기 시간**입니다. 곡이 바뀌어도 소리 감지, 12초 수집, 네트워크 응답 시간이 필요합니다. 소리 감시는 로컬에서 계속되므로 “무음이면 완전히 잠든 상태”는 아닙니다.

음성과 배경음악이 함께 나오는 경우에는 상태/설정 창에서 `빠른 음성 억제`를 선택할 수 있습니다. 이 기능은 별도 대형 AI 모델을 설치하지 않고 주파수 영역에서 음성 대역을 줄이는 빠른 전처리입니다. 인식률을 높일 수 있지만, 음성·음악을 완벽하게 분리하지는 않습니다.

## 설치 파일과 설정

| 파일 | 역할 |
| --- | --- |
| `start.bat` | 일상 실행 진입점. `pythonw.exe`로 콘솔 없이 앱 시작. 첫 설치가 필요하면 디버그 스크립트 호출 |
| `start_debug.bat` | 가상환경 생성, 패키지 설치, 콘솔 유지 실행 |
| `launcher.py` | 중복 실행 방지, 기존 창 활성화, 오류 로그와 시작 오류 알림 |
| `app.py` | 트레이, UI, WASAPI 감시/캡처, 검색 작업 |
| `core.py` | 메모리 내 WAV 작성, 빠른 음성 억제, 결과 정리, 중복 판정 키 |
| `requirements.txt` | Python 라이브러리 목록 |
| `musiclens-error.log` | 회전형 오류·진단 로그 |

설정은 **실행 중 메모리에만** 있습니다. 앱을 다시 켜면 자동 인식은 켜짐, 주기는 15초로 돌아갑니다. Windows 로그인 시 자동 실행은 등록하지 않습니다. 시스템 전체 소리 중 특정 브라우저나 탭만 선택하는 기능은 없습니다.

## 문제 해결

- **`start.bat` 창이 바로 닫힘:** 일상 실행에서는 정상입니다. 시계 옆 숨겨진 아이콘 영역을 확인하세요. 이미 실행 중이면 상태 창이 열립니다. 아이콘도 창도 없다면 `start_debug.bat`를 실행하고 `musiclens-error.log`를 확인하세요.
- **예전 동작이 계속됨:** 실행 중인 앱은 파일 교체를 즉시 반영하지 않습니다. 트레이 메뉴에서 종료하고 다시 실행하세요.
- **`TypeError` 등 검색 오류:** 설치된 ShazamIO와 코드가 맞는지 확인하세요. 현재 확인한 설치 버전은 ShazamIO 0.8.1입니다. 디버그 창과 로그의 최신 오류를 확인하세요.
- **곡을 찾지 못함:** Windows 기본 출력 장치가 실제 재생 장치인지, 재생음이 충분히 크고 12초 이상 이어지는지 확인하세요. 대사와 효과음이 섞이거나 원곡이 변형되면 일치하지 않을 수 있습니다.
- **Shazam 429 또는 시간 초과:** 정확한 비공식 호출 한도는 공개되어 있지 않습니다. 앱은 429를 직접 받았을 때 10분 쉬도록 작성되어 있지만, ShazamIO 내부 재시도와 앱의 22초 제한 때문에 먼저 시간 초과로 보일 수 있습니다. 10분은 서버 공식 정책이 아닌 앱의 자체 보호값입니다.
- **출력 장치를 바꿈:** 장치 변경 직후 오류가 나면 앱을 종료하고 다시 실행하세요.

## 개인정보, 자원, 제약

- 12초 원본 PCM과 WAV는 메모리에서만 처리합니다. ShazamIO는 로컬에서 지문을 생성해 네트워크로 검색합니다. 로그에는 예외와 파일 경로 등이 남을 수 있지만, 원본 음원 파일은 저장하지 않습니다.
- 소리 감시는 기본 출력 장치의 전체 믹스를 읽습니다. 여러 탭의 소리는 분리되지 않습니다. 보호된 오디오나 캡처를 허용하지 않는 재생 경로는 인식되지 않을 수 있습니다.
- 네트워크 연결이 필요합니다. 비공식 Shazam 접근에 대해 확정된 무료 호출량이나 SLA는 없습니다.
- 로그는 최대 약 512KB 파일과 백업 1개로 회전합니다. CPU, 메모리, 배터리 사용량은 별도로 측정하지 않았습니다.

## 개발, 테스트, 배포

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

현재 테스트는 핵심 데이터 변환, ShazamIO 호출 형태, 소리 감지 조건을 확인합니다. 실제 음악을 통한 장시간 자동 인식, 다양한 오디오 장치, 서버 호출 제한은 자동 테스트로 보장하지 않습니다.

`build_exe.bat`는 PyInstaller를 설치하고 `dist\MusicLens\MusicLens.exe` 폴더형 실행 파일을 생성하도록 작성되어 있습니다. 이 빌드 경로의 실제 산출물과 설치 프로그램은 아직 검증하지 않았습니다.

구현 세부 사항은 [개발명세서](DEVELOPMENT_SPEC.md), 모바일 이식 검토는 [모바일 타당성 검토](MOBILE_FEASIBILITY.md)를 참고하세요.
